# AI Telegram Bot

Telegram-бот на Python с использованием Aiogram и OpenAI API.

## Возможности

### GPT-чат

Команда `/gpt`

Позволяет общаться с GPT в режиме диалога. Бот сохраняет контекст последних сообщений для более естественного общения.

### Случайные факты

Команда `/random`

Генерирует интересные случайные факты с помощью GPT. Пользователь может запросить дополнительные факты через встроенные кнопки.

### Общение с известными личностями

Команда `/talk`

Позволяет выбрать одну из известных личностей и вести диалог от её имени.

Доступные персонажи:

* Альберт Эйнштейн
* Дональд Трамп
* Роберт Дауни-младший

### Викторина

Команда `/quiz`

Функционал:

* выбор темы;
* генерация вопросов через GPT;
* проверка ответов пользователя;
* подсчёт очков;
* смена темы;
* завершение викторины.

Доступные темы:

* Животные
* Игры
* Школьные вопросы
* Еда

### Переводчик

Команда `/translate`

Перевод текста на выбранный язык:

* Английский
* Немецкий
* Китайский
* Японский

### Рекомендации

Команда `/recommend`

Подбор рекомендаций по выбранной категории и предпочтениям пользователя.

## Используемые технологии

* Python 3.12+
* Aiogram 3
* OpenAI API
* FSM (Finite State Machine)
* AsyncIO

## Установка

Клонировать репозиторий:

```bash
git clone <repository_url>
cd <project_name>
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл `.env`:

```env
BOT_TOKEN=your_telegram_token
OPENAI_API_KEY=your_openai_api_key
```

Запустить бота:

```bash
python main.py
```

## Структура проекта

```text
handlers/
images/
keyboards/
prompts/
services/
states/

```

* handlers — обработчики команд и сообщений
* keyboards — inline и reply клавиатуры
* prompts — системные промпты для GPT
* services — работа с OpenAI API
* states — FSM состояния
* images — изображения для режимов бота
